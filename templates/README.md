# RoomKit React 템플릿

[RoomKit 문서 홈](../docs/TOC.md)

세 템플릿은 각각 독립적인 Vite + React + TypeScript 프로젝트입니다. 필요한 디렉터리만 복사해서 별도 저장소에서 사용하실 수 있습니다.

| 템플릿 | 선택 기준 |
| --- | --- |
| [`hintphone`](./hintphone/README.md) | Player 안에서 코드 입력과 단계별 힌트를 제공하려고 할 때 사용해 주세요. |
| [`web`](./web/README.md) | Player 안의 웹사이트가 자막과 비디오를 직접 렌더링해야 할 때 사용해 주세요. |
| [`web_custom`](./web_custom/README.md) | Player 없이 브라우저 자체가 RoomKit 장치로 접속해야 할 때 사용해 주세요. |

각 템플릿의 README에 RoomKit 애셋 구성, 로컬 테스트와 배포 방법을 정리했습니다.
