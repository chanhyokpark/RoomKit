# RoomKit Documentation for AI Agents

The AI-facing documentation moved to the **roomkit skill**: [`skills/roomkit/SKILL.md`](../skills/roomkit/SKILL.md) with the reference documents under [`skills/roomkit/references/`](../skills/roomkit/references/).

Install it into a project with the RoomKit CLI (`rk skill install`, also run by `rk init`), or read it directly with `rk docs list` / `rk docs read references/<name>.md`. See [`skills/roomkit/references/cli.md`](../skills/roomkit/references/cli.md) for the CLI reference.

The shorter Korean user documentation starts at [TOC.md](./TOC.md).
