# 테마 제작하기

[문서 홈](../TOC.md) · [이전: 설치하고 실행하기](./getting-started.md) · [다음: 테스트하고 운영하기](./operations.md)

## 권장 제작 순서

1. 테마와 제한 시간을 만들어 주세요.
2. 방 안의 논리적 장치를 등록해 주세요.
3. 스피커 장치와 화면 장치를 묶은 플레이어 애셋을 만들어 주세요.
4. 웹사이트와 미디어 애셋을 준비해 주세요.
5. 진행 순서에 맞게 페이즈를 만들어 주세요.
6. 트리거와 시퀀스를 가진 이벤트를 작성해 주세요.
7. 테스트 세션에서 전체 흐름을 검증해 주세요.

## 애셋 종류

| 종류 | 주요 설정 |
| --- | --- |
| 장치 | 접속 코드, 표시 이름, 힌트 장치 여부, 힌트 코드 CSS를 설정합니다. |
| 플레이어 | 스피커·스크린 장치, 자막 CSS, 대사/SFX 중 BGM 볼륨을 설정합니다. |
| BGM/SFX/비디오 | 파일 또는 플레이스홀더 재생 시간, BGM 페이드, 비디오 위치와 JSON 파라미터를 설정합니다. |
| 대사 | 여러 음성 라인, 라인별 HTML 자막, 재생 후 자막 유지, JSON 파라미터를 설정합니다. |
| 이미지/파일 | 웹사이트가 `/api/media/{assetId}`로 사용할 정적 자료입니다. |
| 웹사이트 | 외부 URL 또는 `index.html`이 포함된 정적 ZIP을 등록합니다. |
| 메시지 | 장치에 보낼 값의 필드 이름과 타입을 정의합니다. |
| 힌트 | 고유 코드, 단계별 HTML·이미지, 선택적인 정답과 JSON 파라미터를 설정합니다. |
| 페이즈 | 게임 진행 순서를 설정합니다. |
| 이벤트 | 페이즈, 트리거, 실행 옵션과 커맨드 시퀀스를 설정합니다. |

미디어 파일이 아직 없다면 `fileKey` 없이 재생 시간만 지정해 주세요. Player와 테스트 장치는 그 시간 동안 플레이스홀더를 표시하고 정상적으로 완료 응답을 보냅니다.

ZIP 일괄 업로드는 BGM, SFX, 비디오와 대사를 빠르게 만들 때 유용합니다. 대사는 `name_1.mp3`, `name_2.mp3`처럼 이름을 붙이면 하나의 대사 애셋으로 묶입니다.

## 이벤트와 트리거

이벤트는 특정 페이즈에 소속시키거나 모든 페이즈에서 사용할 **공통 이벤트**로 만들 수 있습니다.

- **장치 트리거**는 장치나 웹사이트가 이름과 선택적인 JSON payload를 보낼 때 실행됩니다.
- **수동 트리거**는 운영 화면에서 버튼으로 실행합니다.
- **시스템 트리거**는 `session:start`, `phase:enter`, `phase:leave`, `timer:expired`에 실행됩니다.
- **재진입 허용**을 끄면 같은 이벤트가 실행 중일 때 중복 실행되지 않습니다.
- **1회만 실행**을 켜면 세션에서 한 번만 실행됩니다. 페이즈를 재시작하면 해당 페이즈의 실행 기록도 초기화됩니다.

트리거 payload는 `{{payload.key}}` 또는 eval의 `ctx.payload`로 사용하실 수 있습니다. 세션 변수는 `{{vars.key}}`로 치환할 수 있습니다.

## 주요 커맨드

- **재생**: 대사, BGM, SFX, 비디오를 재생하거나 정지합니다.
- **장치**: 장치 초기화, 모든 장치 초기화, 웹사이트 이동, 메시지 전송, 웹사이트 HTTP 요청, 힌트 코드 표시·숨김을 처리합니다.
- **흐름**: 대기, 페이즈 전환, 이벤트 호출, JavaScript 실행, 테마 종료를 처리합니다.
- **타이머**: 시간을 더하거나 빼고, 타이머를 일시정지하거나 재개합니다.
- **운영**: 운영 화면에 알림을 표시합니다.

**끝날 때까지 대기**를 켜면 재생 종료, 사이트 로드 또는 메시지 처리 완료 응답을 받은 뒤 다음 커맨드를 실행합니다. 완료 응답이 필요한 커스텀 코드를 작성하실 때는 누락되지 않도록 주의해 주세요.

대사의 **라인 사이 커맨드**는 특정 대사 라인 다음에 작은 시퀀스를 실행합니다. 스피커가 다음 라인 전에 멈추고, 커맨드가 끝난 뒤 재생을 계속합니다.

## JavaScript 실행

JavaScript는 서버의 제한된 `node:vm` 환경에서 최대 1초 동안 동기 실행됩니다.

```js
ctx.vars.keys = (ctx.vars.keys ?? 0) + 1;
if (ctx.vars.keys < 3) return false;
ctx.notify('모든 열쇠를 찾았습니다.');
ctx.switchPhase('탈출');
```

사용 가능한 값과 함수는 다음과 같습니다.

- `ctx.vars`: 세션 동안 유지되는 공유 변수입니다.
- `ctx.payload`: 현재 트리거 payload입니다.
- `ctx.phase`: 현재 페이즈 이름입니다.
- `ctx.trigger(name)`, `ctx.log(message)`: 이벤트를 발생시키거나 로그를 남깁니다.
- `ctx.switchPhase`, `ctx.notify`, `ctx.adjustTimer`, `ctx.endTheme`: 스크립트가 끝난 뒤 순서대로 실행할 작업을 예약합니다.
- `return false`: 현재 시퀀스의 나머지를 중단합니다.

관리자가 작성한 코드만 실행해 주세요. eval 코드는 보안 경계가 아니라 신뢰하는 제작자를 위한 기능입니다.
