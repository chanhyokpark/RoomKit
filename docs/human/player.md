# Player 설정하기

[문서 홈](../TOC.md) · [이전: 설치하고 실행하기](./getting-started.md) · [다음: 테마 제작하기](./authoring.md)

RoomKit Player는 서버에 플레이어 런처로 등록되고, 각 장치 코드를 별도 스테이지 창에서 실행합니다. 스테이지는 웹사이트, BGM, 효과음, 대사·자막, 비디오, 플레이스홀더와 힌트 코드 오버레이를 처리합니다. `pnpm infra`에는 Player가 포함되지 않으므로 방 안 컴퓨터나 개발 머신에서 별도로 실행해 주세요.

## 런처와 장치 창

1. **서버 URL**에는 장치에서 접근할 수 있는 RoomKit Server 주소를 입력해 주세요.
2. **플레이어 이름**은 Studio의 연결된 플레이어 목록에 표시됩니다.
3. **디바이스 추가**로 라벨, 프로덕션 장치 코드 또는 테스트 코드를 저장해 주세요.
4. 데스크톱에서는 **열기**로 한 창만 열거나 **모두 열기**로 코드가 있는 모든 장치 창을 열 수 있습니다.

설정은 앱 데이터 디렉터리에 자동 저장됩니다. 같은 장치를 다시 열면 중복 창을 만들지 않고 기존 창에 포커스합니다. Studio에서 연결된 Player를 골라 테스트 세션이나 웹 테스트를 만들면 임시 코드가 발급되고 해당 창이 자동으로 열립니다. 이 자동 테스트 창은 런처에 저장한 장치 목록을 변경하지 않습니다.

## 미디어 캐시

Tauri 앱의 스테이지는 서버에 연결될 때 해당 장치 역할에 필요한 파일 목록을 받아 백그라운드에서 내려받습니다.

- 플레이어 애셋에서 스피커로 지정된 장치는 BGM, SFX와 대사 라인을 받습니다.
- 스크린으로 지정된 장치는 비디오를 받습니다. 자막 자체는 커맨드에 포함되므로 별도 파일이 아닙니다.
- 파일은 변경되지 않는 `fileKey`를 기준으로 재사용하고, 최신 목록에서 빠진 파일은 정리합니다.
- 동기화나 개별 파일 다운로드가 실패하면 재생 커맨드의 임시 URL로 스트리밍하므로 캐시는 필수 조건이 아닙니다.
- 브라우저용 `dev:web` 실행에서는 로컬 Tauri 캐시를 사용하지 않습니다.

테스트 창 상단에는 캐시 동기화 진행률이 표시됩니다. HTTPS Helper 사이트가 비디오 렌더링을 맡은 경우 Player는 캐시 파일을 `blob:` URL로 전달하므로 사이트는 Helper가 준 URL을 그대로 사용해 주세요.

## 테스트 세션 도구

테스트 세션의 스테이지에만 상단 **TEST** 바가 표시됩니다.

- 세션 상태, 남은 시간, 판정, 연결 상태와 캐시 진행률을 확인할 수 있습니다.
- 장치 트리거 이름을 직접 전송하고 최근 이름을 다시 사용할 수 있습니다. 이 입력은 JSON payload를 지원하지 않으므로 payload 테스트에는 웹사이트, 커스텀 장치 또는 MCP를 사용해 주세요.
- 실행 중인 대사와 비디오는 건너뛰기 버튼으로 완료 처리할 수 있습니다. 해당 재생을 기다리던 시퀀스는 다음 커맨드로 진행합니다.
- 세션이 일시정지되면 화면 중앙에 상태가 표시됩니다.

프로덕션 장치에는 TEST 바와 건너뛰기 버튼이 나타나지 않습니다.

## 키오스크 모드

런처에서 장치별 **키오스크**를 켜면 수동으로 연 데스크톱 스테이지 창이 전체 화면·항상 위 상태가 되고, 닫기와 일반 브라우저 단축키를 최대한 막습니다. 잠금을 해제하려면 `Ctrl+Shift+Alt+F12`를 누르고 확인해 주세요.

이 기능은 앱 수준의 잠금입니다. `Alt+Tab`, Windows 키, `Ctrl+Alt+Del` 같은 운영체제 단축키까지 막지는 못합니다. 강한 잠금이 필요하면 Windows Assigned Access 같은 OS 키오스크 기능을 함께 사용해 주세요. Studio가 자동으로 연 테스트 창은 키오스크 모드를 사용하지 않습니다.

## Android의 제한

Android는 여러 데스크톱 창을 지원하지 않아 한 번에 한 장치만 실행합니다. 장치를 열거나 Studio가 테스트를 시작하면 런처 화면 자체가 첫 번째 스테이지로 바뀌며, 같은 요청의 나머지 장치는 열리지 않습니다. 런처로 돌아가려면 앱을 완전히 종료한 뒤 다시 실행해 주세요.

데스크톱 앱은 `pnpm --filter player build:app`, Android APK는 Android SDK/NDK를 준비한 뒤 `pnpm --filter player build:android`로 빌드할 수 있습니다.
