# 테스트하고 운영하기

[문서 홈](../TOC.md) · [이전: 테마 제작하기](./authoring.md)

## 테스트 방법 선택하기

빠른 방법부터 차례로 사용해 주세요.

1. **웹 테스트**로 개발 중인 웹사이트와 Helper 통신을 확인해 주세요.
2. **테스트 세션**으로 실제 이벤트, 타이머와 여러 장치를 함께 확인해 주세요.
3. Player가 없으면 AI/MCP의 **가상 장치**로 로직과 로그를 먼저 검증해 주세요.
4. 최종 단계에서 실제 Player와 방 안 장치로 타이밍과 음량을 확인해 주세요.

## 테스트 세션

테스트 세션은 여러 개를 동시에 만들 수 있으며 세션별 장치 코드를 발급합니다.

- 연결된 Player를 선택하면 런처가 장치별 창을 자동으로 열 수 있습니다.
- 직접 입력을 선택하면 원하는 테스트 코드를 발급해 `@roomkit/client` 장치에 전달할 수 있습니다.
- 세션은 **시작 전** 상태로 만들어지므로 장치 연결을 먼저 확인하실 수 있습니다.
- 세션을 시작하면 타이머, `session:start`, 초기 `phase:enter` 이벤트가 실행됩니다.

## 운영 화면

- **타이머**에서 시간을 조정하거나 타이머만 일시정지할 수 있습니다.
- **페이즈**를 강제로 전환하거나 현재 페이즈를 재시작할 수 있습니다.
- **수동 이벤트**에서 허용된 이벤트를 실행할 수 있습니다.
- **힌트 전송**으로 코드 입력을 거치지 않고 특정 단계를 보여 줄 수 있습니다.
- **디바이스** 카드에서 접속 상태와 현재 재생 중인 항목을 확인하고 정지할 수 있습니다.
- **실행 중 이벤트**에서 멈춘 시퀀스를 강제로 중단할 수 있습니다.
- **로그**에서 트리거, 커맨드, eval, 힌트와 장치 오류를 실시간으로 확인할 수 있습니다.

페이즈 재시작은 현재 페이즈의 실행 중인 이벤트를 중단하고, 해당 페이즈에 속한 1회 이벤트 기록을 초기화한 뒤 leave/enter 훅을 다시 실행합니다. 공통 이벤트의 1회 기록은 초기화하지 않습니다.

## 실제 운영 흐름

1. 프로덕션 세션을 만들어 주세요. 테마 하나에는 종료되지 않은 프로덕션 세션을 하나만 만들 수 있습니다.
2. 장치가 모두 온라인인지 확인해 주세요.
3. 필요하면 **시작 전 모든 디바이스 초기화**를 선택하고 세션을 시작해 주세요.
4. 진행 중에는 로그, 페이즈, 타이머와 실행 중 이벤트를 확인해 주세요.
5. 테마 종료 커맨드 또는 운영자의 종료 동작으로 결과를 기록해 주세요.
6. 세션 결과에서 플레이 시간, 힌트 사용과 운영 개입을 확인해 주세요.
7. 다음 팀을 받기 전에 모든 장치를 초기화하고 새 세션을 만들어 주세요.

## 완료 응답과 중단

재생 정지 버튼은 장치가 정상적으로 재생을 마친 것처럼 완료 응답을 보냅니다. 따라서 해당 미디어를 기다리던 시퀀스는 다음 커맨드로 진행합니다. 반면 **실행 중 이벤트 강제 종료**는 기다림을 취소하고 남은 커맨드를 실행하지 않습니다.

오프라인 장치로 보내는 커맨드는 실패 로그를 남기고 즉시 다음으로 진행합니다. 온라인 장치가 완료 응답을 보내지 않으면 기다리는 시퀀스가 멈출 수 있으므로 실행 중 이벤트 카드와 로그를 함께 확인해 주세요.
